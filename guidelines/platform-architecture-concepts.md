# Platform architecture visual direction

The production image uses the revised **three-layer original-iconography direction**. It restores the complete icon vocabulary from the original platform diagram while simplifying the structure to the three deployable architecture tiers.

## Concepts

1. **Gap band** — Preserves the familiar four-band reading order, but uses a dashed sage band and an explicit “not a tier” label. Best when continuity with the previous visual matters most.
2. **Three-layer original iconography (production)** — Removes the context sidecar, restores the platform, ecosystem, and plant icon sets, and centers each layer title. The legacy `b-context-sidecar` filename is retained so existing review links continue to work.
3. **Accountability bridge** — Uses open space and bracket lines between the platform and existing ecosystem. This presents the pain points as a transition to be closed, not a system to deploy.
4. **Diagnostic lens** — Reduces the pain points to five compact themes in a floating lens. This has the lowest visual weight and works when architecture should dominate.

All concepts are 3840 × 2160 transparent PNGs in `public/images/platform/concepts/`. The production source and its 1440/960 AVIF and WebP variants are generated by `scripts/generate-platform-architecture.py`.
